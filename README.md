# Real Page PPP

## Structure

This repository contains a web application with the following structure:

- **css/** - CSS stylesheets
- **fonts/** - Font resources
- **images/** - Image assets
- **js/** - JavaScript files
- **media/** - Audio/media files
- **index.html** - Main HTML page
- **w1.html, w3.html** - Additional HTML pages
- **bg1.jpg, logo.jpg** - Image assets
- **css.zip** - Archive of all web assets (already extracted)

## Usage

Open `index.html` in a web browser to view the application. All required assets (CSS, JavaScript, images, fonts, and media files) are available in their respective directories.
